## 教学修订与边界

只读教学研究核对未发现阻断性语法错误，发现三处文案需要修订，已保留 ID 并修复：

- c12-m5-q5：实际修饰对象是 picture，题干误写 book，已更正。
- c12-m3-q1：把“普通、无强调的表达”限定提前到题干；强调 do 不能脱离语境一律判错。
- c19-m3-q2：短答 At nine 的正确选项改为“可以，问句提供省略部分的语境”，避免误说问句给出“离开什么”。

原有 689 个题目 ID 均保留；686 题内容不变，3 题只更正上述字段。qa/v17-corrections.json 包含修订前后字段与原因；指纹检查只允许这些明确变更，不对旧题任意放宽。原有存档按题目 ID 保留，修订文案不清除已完成记录。

精修重点：时间与体不机械一一对应；愿望与事实分开；一致看主语核心和具体变体；被动保持施受与时间；方向不保证到达；从句内部角色与外部功能分开；关系词省略和逗号有条件；连接词决定逻辑；比较保持维度；活动内部保留动词性质；不定式不一律表示将来；分词后缀不直接等于时间或主动被动；省略必须可恢复。try doing/try to do 和 regret doing/regret to inform 增加语境对比。

本应用保留传统入门术语和五种句型模型。集合名词、wish 后 was/were、who/whom 等变体不在缺少语境时作绝对判断。普通分词状语的参与者对应规则不替代独立结构或特殊补充结构。自由造句与任意删词不由程序自动判为唯一正确，只核验给定选项或词块。
