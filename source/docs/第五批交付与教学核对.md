## 教学审查

- 关系从句要看先行片段和内部缺口。who 自身可作主语，不重复 she；whom 是较正式宾语形式，但不教成口语永远必须用 whom。
- where/when 看从句缺地点或时间关系，不能只看先行词类别；the garden which Mia visited 中 visited 缺宾语，与 where Mia plays 不同。
- 限定 which 可以成立，不把 which 一概排除；非限定关系从句不用 that、不按限定宾语规则省关系代词。人名或亲属称呼是否受限定，要看语境而非一刀切。
- 内容从句 the news that Mia won 与关系从句 the news that Mia shared 分开。前者不是用删 be 的万能规则生成，也不把所有 that 都当关系代词。
- 省略宾语关系词有结构条件；介词前置后用 whom/which 并保留。精简关系从句只采用自然的分词或介词短语示例，不教“见 be 就随意删”。
- 状语机关不以卡片左右推断时间或因果。before 从句在左时，其事件可能晚于主句事件；关系灯只代表试接，不代表两件事相邻就证明因果。
- if 普通开放条件未必实现；even if 的假设让步与 although/even though 陈述的让步情境区分。so that 表目的时不保证目的已实现；so...that、such...that 结果结构另认。
- 同一层关系不重复 although...but；不推广成整句或整段永远不能同时出现这两个词。状语从句标点采用常见清晰形式，不把所有后置从句都教成绝不能加逗号。
- 普通将来时间/条件从句的现在式用法有语境，联系第 8 章假想条件，避免把所有 if 强塞同一公式。
- 词、短语、分句可以各自并列，不强行宣称所有并列词组都由完整句子删除而来。比较结构不简单等同于普通 and 并列；重复 that 帮助层级清楚，但不一概称为永远不可省。
- 比较对象和维度必须对应。图形是相对刻度，不是质量天平或学习能力评价；切换身高/书数/速度时数据同步显示。
- 比较级/最高级包括常见拼写与词汇例外。as...as 中用原级；more 不与 taller 叠加。fewer 用于本题可数复数，less water 对应不可数用法。
- 比较对象由上下文给出时可以说 This box is bigger，不武断判错。I like Mia more than Leo 有潜在歧义，按任务补足重复结构消歧。
