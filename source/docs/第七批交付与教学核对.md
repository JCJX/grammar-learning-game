## 教学核对与边界

1. 词性是本次语境中的类别，句子成分是功能。名词不等于主语，形容词不等于定语，副词不等于所有状语。两个步骤帮助学习者先找词块，再判断其工作；不把图上颜色当作语法证明。
2. 主语可为整组名词短语。宾补说明宾语，双宾语中的接收者和递交物不是同一对象。五种句型仍是入门框架；可删修饰只用于明确可选的本例，不声称 put 后位置等都能自由删除。
3. 计量单位变复数，物质用法不直接加 s；抽象与可数性分开。三条画像线索求交集，不能凭单条相似特征选人。普通词序与具体语境优先，不把一种排列当作全部合法表达。
4. be 专题：区分系动词与进行、被动助手。含明确 by 施事的被动例句减少状态/事件歧义。名词短语 the book on the desk 不是普通完整陈述；不沿用“所有定语和宾补都来自删 be”的万能生成解释。
5. used 专题：used to + 原形表示过去习惯或状态；be/get/become used to 中 to 为介词，接名词、代词或 -ing。get 强调适应过程，不等于已完全熟悉。熟悉结构可用于过去、现在和将来。be used to do 的工具用途属于 use 的被动与目的结构，不等于习惯。
6. did 后采用本课常见书写 use to；不拿 used to 代替单次具体过去事件。不把 used to 说成 will 的任意过去替换。used book 和 used a brush 分别认识为使用过的、使用的过去式。
7. it 专题：指代依上下文，形式主宾语依自然具体搭配；不能任意后移长结构。天气/时间 it 不强找实物。强调改变焦点，保留事件参与者与关系；表面 It is ... that 不足以脱离语境判断唯一结构。
8. 原书把 make it to the party 同一些空主语例句并列，本版用固定表达“成功到场/赶到”解释；不把它归为天气主语，也不声称整个表达毫无意义。形式主语与 empty/dummy 的术语在不同体系可能重叠，本版按教学功能分别展示。
9. 六个新机制使用给定方案，不实现任意英语自由生成判断。used 的空格先隐藏待选内容；选轨道与后接形式后才检查。动画始终标为试选示意，不将熟悉程度变成虚构精确测量。
