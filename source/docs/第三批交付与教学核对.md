## 教学审查与边界

- 沿用教材“十二时态”的常见教学名称，但将来可由多种结构表达，will 不是唯一方式；不把一般式等同于频繁发生。
- 完成镜头从参照点回望，不宣称完成式必然表示状态已结束；完成进行可刚停止而留下结果。一般过去本身不证明现在相反。
- 情境明确要求镜头和时间；不把其他语境中的合法形式一概标错。进行结构不保证从参照点才开始，状态动词也按具体用法理解。
- wish 的过去形式可以指现在。非现实 were 是较正式常用形式，但不宣称口语 was 永远错误；as if 不必永远反事实。愿望不证明未来事实。
- would have done 是情态完成结构，不称作“情态词后的现在完成时”；mixed 条件分别确定两个分句时间。would rather 区分是否更换主语。
- I 是第一人称单数，不能因 I have 就称作“复数”；不是所有动词都显式体现主谓单复数变化。
- of 结构不能一律看最近名词；the number of 与 a number of 分开，数量结构按指代对象理解。避免用 none of + 复数名词出有争议的单选。
- 集合名词解释英美差异；单个活动/问题通常单数，但不推广成所有从句和并列活动永远只能单数。
- 动画用于关系示意。乐手数量不取代语法人称规则；选择后亮灯/接桥是试演而不是正确判定。减少动画模式保留静态关系、标签和任务信息。
